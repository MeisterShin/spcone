# 체크인 개선 3종 설계 (차량번호 일괄입력 · VIP 사진 확인 · 게이트 모드 스위치)

## 배경
사용자 요청 3건(그대로 인용):
1. "의전대상 명단 일괄 입력할 때 차량번호 정보 입력 추가"
2. "VIP 할 때 체크버튼을 통해 사진도 확인할 수 있게 사진은 의전대상 명단에서 추가, 언체크시 지금처럼 나오는걸로"
3. "주차장, 입구, 체크인 또한 모드 변경을 통해 단일 체크인 버튼만 노출하는 모드와 전환"

사용자 확인 사항: 사진 토글은 페이지 상단 전체 토글 1개, VVIP+VIP 둘 다 적용, 게이트 모드 스위치는 행사에 저장(모든 담당자 공통).

## 1. 차량번호 일괄입력

### 데이터 모델
`guests`(내빈 기본정보 마스터)에 `vehicleNo`(기본 차량번호) 추가. 기존 `eventGuests.vehicleNo`(행사별 차량번호)는 그대로 유지 — 행사 배정 시 마스터의 기본값을 **상속**하되, 행사별로 개별 수정 가능(기존 "내빈 행사 설정" 모달의 차량번호 입력은 그대로 둠).

### 변경 지점
- "명단 일괄등록" 붙여넣기 열 순서에 차량번호 추가: `이름·소속·직위·등급·그룹·차량번호`(6번째 열, 선택 입력).
- 내빈 기본정보 개별 추가/수정 모달에도 "기본 차량번호" 입력 필드 추가(일괄 등록이 아닌 개별 등록도 동일하게 지원).
- 행사 배정(`commitAssign`) 및 긴급 내빈 추가 시, 신규 `eventGuests.vehicleNo`를 `guests.vehicleNo||''`로 초기화(빈 문자열 하드코딩 대신 상속).

## 2. VIP 사진 확인

### 데이터 모델
`guests`에 `photo`(base64 데이터 URI, 클라이언트에서 240×240으로 리사이즈·압축한 값) 추가. 없으면 기존과 동일하게 이니셜 아바타.

### 업로드 UI
내빈 기본정보 추가/수정 모달에 사진 업로드(파일 선택 + 미리보기 + "사진 제거" 버튼) 추가. 브라우저에서 `FileReader`+`canvas`로 리사이즈·JPEG 압축 후 저장 — 원본 그대로 저장하지 않아 Firestore 문서 크기·로딩 속도 문제를 피함.

### 확인 UI (현장 체크인)
현장 체크인 페이지 상단에 토글 버튼 "VIP 사진 표시"(기존 "오프라인 시연" 버튼과 같은 자리·스타일) 추가.
- **켜짐**: VVIP·VIP 등급 카드는 사진이 있으면 이니셜 대신 사진을 아바타 자리에 표시(사진 없으면 이니셜 유지).
- **꺼짐(기본값)**: 지금과 완전히 동일하게 이니셜만 표시.
- Guest 등급은 토글 상태와 무관하게 항상 이니셜.

## 3. 게이트 모드 온/오프 스위치

### 데이터 모델
`events`에 `gatesEnabled`(boolean) 추가. 게이트 배열(`gates`)은 그대로 두고, 이 스위치로 "게이트 버튼 모드"와 "단일 체크인 버튼 모드"를 **게이트 목록을 지우지 않고** 전환.

### 규칙
- `gatesEnabled`가 명시적으로 `false`가 아니면(즉 `true`거나 아직 설정 안 된 기존 행사) **그리고** `gates.length>0`이면 게이트 모드.
- 행사 생성/수정 모달의 "게이트(동선)" 섹션 맨 위에 체크박스 "게이트(동선) 모드 사용 — 끄면 현장 체크인에서 단일 체크인 버튼만 표시" 추가(기본 체크됨).
- 행사에 저장되므로 이 행사를 보는 모든 담당자에게 동일하게 적용(사용자 확인 사항).

## 에러 처리
- 사진 업로드 실패(파일 형식 오류 등)는 조용히 무시하고 기존 사진(또는 없음) 유지 — 별도 에러 다이얼로그 없음.
- 사진·차량번호 모두 선택 입력이며 없어도 기존과 동일하게 동작(회귀 없음).

## 테스트
- 차량번호 일괄입력 파싱, 마스터→행사 상속(assign·urgent-add) 로직.
- 사진 저장 시 "변경 없음/제거/신규 교체" 3가지 저장 로직(실제 이미지 리사이즈는 브라우저 전용이라 자동테스트 대상 아님 — 육안 확인으로 대체, 기존 드래그앤드롭 태스크와 동일한 전례).
- 사진 토글 on/off에 따른 VVIP/VIP/Guest 아바타 렌더링 분기.
- 게이트 모드 스위치: `gatesEnabled=false`면 게이트가 있어도 단일 버튼 모드로 돌아가는지, 기존(스위치 미설정) 행사는 게이트 있으면 게이트 모드 유지(회귀 없음)되는지.

## 범위 밖
- 사진은 내빈 "기본정보"(마스터)에만 저장 — 행사별 사진 없음.
- 차량번호 일괄입력 외 다른 열(수행원 등) 추가 없음.
